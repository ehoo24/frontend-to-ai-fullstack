前端转 AI 全栈：从交互体验到生产级交付

跨越“会调用模型 + 会写页面”与“生产级 AI 全栈”的真正分水岭。建立能持续交付、可上线、能排错、控风险的端到端工程能力，贯穿打造带权限的企业知识库 Copilot 实战系统。

📚 全套 12 核心实战章节 ⏱️ 预计学习周期：35–45 小时 🛡️ 具备 0 外部依赖确定性质检 (0 error, 0 warning) 🎯 适用对象：熟练前端开发者、独立开发者、全栈工程师

模块一：认知重塑与端到端工程基石

第 01 章 75–90 分钟

认知重塑：为什么会调用 API 不等于 AI 全栈

从一起真实的前端直连 Token 泄漏事故切入，剖析玩具 Demo 与生产级系统的分水岭，建立四层能力模型与主次演进路线。
第 02 章 80–100 分钟

服务端工程基石：REST 规范、参数校验与端到端类型契约

结合 Fastify 与 Zod，实现编译期与运行时双重类型保护，建立统一错误响应与前后端共享类型架构。

模块二：后端工程与核心存储

第 03 章 · 深度核心 90–120 分钟

核心数据存储：PostgreSQL 关系建模、事务与 pgvector 向量扩展

掌握 PostgreSQL 关系规范化建模、悲观锁事务控制，并在同一库中启用 pgvector 与 HNSW 索引完成向量检索。
第 04 章 85–105 分钟

高并发护城河：Redis 缓存穿透防御、滑动窗口限流与轻量任务队列

攻克缓存三大灾难，用 Redis + Lua 脚本实现毫秒级滑动窗口限流，并借助 BullMQ 异步剥离耗时的向量化任务。
第 05 章 85–105 分钟

生产级安全防护：JWT 认证、RBAC 细粒度权限与 AI 注入防御

搭建双 Token 轮转鉴权与多租户 RBAC 数据隔离，深入剖析 Prompt 注入与敏感词过滤的纵深防御体系。

模块三：生产级 LLM 应用开发

第 06 章 · 深度核心 90–120 分钟

生产级 LLM 服务：SSE 流式长连接、AbortSignal 实时中断与代理网关

深潜 SSE 协议，搭建安全的服务端大模型流式代理，解决前端中断时服务端必须及时切断模型推理防止 Token 跑飞的核心机制。
第 07 章 80–100 分钟

结构化输出与受控工具调用：Zod Schema 校验与业务逻辑闭环

基于受限生成原理实现 100% 可靠的结构化 JSON 输出，掌握 Function Calling 工具调度与失败自愈循环。

模块四：企业级 RAG 架构与质量评测体系

第 08 章 · 深度核心 95–130 分钟

工业级 RAG 检索管线：清洗切分、混合召回、重排与权限隔离

告别玩具 RAG，实现 Markdown 递归切分、tsvector 关键词与 pgvector 语义双路召回、RRF 融合与角标来源溯源。
第 09 章 · 深度核心 85–110 分钟

从“感觉不错”到数据量化：RAG 黄金评测集与成本可观测性

搭建黄金测试集，用 Ragas 度量真实性（Faithfulness）与拒答指标，建立单次请求 Token 计费与全链路追踪监控。

模块五：受控 Agent 架构与生产运维

第 10 章 90–115 分钟

受控业务 Agent：状态机、工具白名单与 Human-in-the-Loop 审核机制

运用有限状态机约束自主 Agent 失控，建立三级工具权限体系，对高风险写入/删除操作实现人工挂起审核与恢复执行。
第 11 章 85–105 分钟

容器化交付、CI/CD 自动化部署与生产环境故障复盘

编写轻量安全的生产级 Dockerfile 与 GitHub Actions 质检门禁，演练数据库平滑迁移回滚，规范输出生产故障复盘报告。

模块六：企业级微服务协同

第 12 章 90–120 分钟

企业级微服务协同：读懂 Spring Cloud、Feign、租户隔离与 Spring AI 流式调用

打通 Node/TS 与 Java Spring Cloud 的架构心智映射，掌握 Controller 到 Mapper 的排障技巧，优化 N+1 查询并安全协作接入 Spring AI。
