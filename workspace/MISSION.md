# 前端转 AI 全栈：从交互体验到生产级交付 (MISSION)

## 一、课程为什么存在

当前 AI 技术浪潮中，大量前端开发者希望向“全栈”及“AI 工程师”转型。然而，业界充斥着两种常见误区：
1. **玩具化陷阱**：认为“用 Next.js 写个聊天界面，前端调用 OpenAI / Gemini API”就等于掌握了 AI 全栈。这忽略了数据边界、认证鉴权、成本控制、并发安全、异常熔断和工程化交付。
2. **堆技术栈陷阱**：盲目从头硬啃重型后端理论（JPA、复杂微服务底层、JVM 调优、模型底层训练），耗时数月却无法独立上线一个稳定的 AI 产品。

本课程的唯一使命是：**帮助具有熟练前端开发经验的工程师，跨越“会调用模型 + 会写页面”与“生产级 AI 全栈”之间的真正分水岭，建立一条能持续交付、可上线、能排错、能控制风险的端到端成长路线。**

学习者将不再把后端视为黑盒，而是掌握四层能力模型（产品交付、服务工程、AI 工程、生产运营），并能独立端到端交付一个高可靠的企业级 AI 知识库系统，同时具备在实际企业团队（如 Java 微服务架构团队）中定位问题、协同开发与排障的能力。

---

## 二、目标受众与受众画像

### 1. 核心受众
- **熟练前端开发者**：具备 2 年以上 JavaScript / TypeScript、React / Vue 开发经验，熟悉现代前端组件化、状态管理、异步 Promise 与网络请求。
- **痛点**：缺乏后端体系化工程思维（数据建模、事务隔离、幂等性、连接池、缓存击穿、错误码规范），面对模型偶发幻觉、慢延迟、高昂 Token 费用以及真实生产环境故障时缺乏排查和兜底手段。

### 2. 次级受众
- **全栈初学者与独立开发者**：希望构建具有商业价值与交付质量的 AI SaaS 产品，需要避开低级安全与架构漏洞。
- **需要与 Java / 后端微服务协作的前端团队核心成员**：需要在现有企业架构（如 Spring Cloud、MyBatis-Plus、Feign、Nacos）中接入 AI 模块或协同排查跨端调用链问题。

## 三、学习者前置知识要求

### 必须具备（先修条件）
- 熟练使用 TypeScript / JavaScript 编写现代前端应用（React 或 Next.js / Vue）。
- 熟练使用 Git 进行日常版本管理（commit、branch、PR/MR、rebase）。
- 理解基础 HTTP 协议概念（GET/POST、Header、Query、Body、状态码、跨域 CORS）。
- 本地配置有 Node.js 18+ 环境与现代 IDE（VS Code / Cursor / WebStorm）。

### 本课程将从零补齐（无需提前自学）
- 服务端框架（Node.js / Fastify / Next.js Route Handlers）的中间件与生命周期。
- 关系型数据库（PostgreSQL）建模、索引、事务 ACID 与 pgvector 向量检索。
- 内存缓存（Redis）在限流、幂等键与轻量队列中的工业用法。
- LLM 流式服务端架构（SSE）、结构化输出校验（Zod）、Prompt 注入防御与成本控制。
- 工业级 RAG 检索管线、黄金评测集（Ragas 维度）与自动化量化评估。
- 受控 Agent 状态机、工具白名单与 Human-in-the-Loop 审核机制。
- Docker 容器化、GitHub Actions 自动化 CI/CD 与故障复盘规范。
- 企业级 Java 微服务项目（Spring Cloud Alibaba、Feign、Gateway）调用链与排障基础。

## 五、学习时间、节奏与使用场景

- **总学习时长**：建议投入 35–45 小时。
- **推荐节奏**：每周投入 6–8 小时，建议分为：
  - 40% 时间：编写主项目核心代码与单元测试；
  - 20% 时间：攻克服务端、数据库与 AI 底层机制；
  - 20% 时间：阅读官方文档、高可用最佳实践与优秀工程源码；
  - 10% 时间：进行注入故障演练与安全防御验证；
  - 10% 时间：撰写工程复盘笔记与架构技术说明。
- **周期**：建议用 6 周时间完成完整迭代。

## 六、内容范围与明确不讲的内容（边界界定）

### 包含的内容（In Scope）
- TypeScript 服务端架构：Fastify 路由、契约校验（Zod/TypeBox）、全局统一错误处理。
- PostgreSQL：表结构建模、外键约束、B-Tree 索引、事务隔离级别与 pgvector 向量检索。
- Redis：分布式缓存、令牌桶/滑动窗口限流、幂等 Token 机制。
- LLM 服务工程：密钥隔离、SSE 流式长连接、AbortSignal 中断处理、结构化输出、工具白名单与安全沙箱。
- 企业级 RAG：Markdown/PDF 文档清洗分块、Embedding 向量化、关键词与向量混合检索（Hybrid Search）、Rerank 重排、按用户角色权限过滤数据。
- 质量评测：黄金测试集构建、上下文相关度、答案保真度（幻觉度量）、无答案拒答机制。
- 受控 Agent：有限状态机、人工审核关键断言（Human-in-the-Loop）、单步执行与回滚。
- 运维实战：多阶段 Docker 构建、GitHub Actions CI/CD 流水线、结构化日志与 APM 链路追踪。
- 团队协同：读懂 Java Spring Boot 3 / Spring Cloud 典型调用链（Controller → Service → Mapper）、多租户上下文传递与 Spring AI 流式接入。

### 明确不讲的内容（Out of Scope / 风险边界）
- **模型底层训练与微调算法**：不讲 PyTorch、CUDA 算子开发、LoRA 权重计算等算法工程师专属领域。
- **纯粹的前端切图与 CSS 动画**：假设学员已有基础前端能力，不花篇幅讲解 Flex 布局或 CSS 基础样式。
- **高深复杂的分布式底层源码**：不讲 Seata 源码内部二阶段提交协议细节，不深挖 JVM 垃圾回收器 GC 算法；只关注如何正确配置、调用、排错与降级。
- **玩具级技术方案**：坚决不教把 API Key 写在前端代码里、不讲没有任何权限校验的纯本地演示 Demo。

## 七、交付格式、运行环境与规范

- **交付形态**：
  - 结构化教程体系（Markdown 事实源，结构严格符合 `teach-yourself-skill` 规范）。
  - 配套可运行的工程项目样板（涵盖 Fastify 后端、Next.js 交互层、Docker 编排配置与 SQL 迁移脚本）。
  - 架构图示：全部采用标准 Mermaid 图表（严格遵循 `flowchart`、`sequenceDiagram`、`stateDiagram`，杜绝禁用图类型）。
- **运行环境**：
  - Node.js >= 20.x, TypeScript >= 5.x
  - PostgreSQL >= 16 (含 pgvector 扩展)
  - Redis >= 7.x
  - Docker Desktop >= 24.x
  - Python >= 3.11 (用于评测脚本副线)
  - Java 21 (用于协同实战阅读与调试，可选环境)
